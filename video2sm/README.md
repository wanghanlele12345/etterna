# video2sm

An MCP server that turns a music video into a playable Etterna / StepMania song, and gives
a language model the senses to choreograph it:
audio, beat-synced `.ssc` charts (4-key and/or 9-key, with hold notes), banner, background image, and the video itself as
the in-game background, written straight into the `Songs/` folder.

## Choreography: the model decides, the code assists

A chart is a dance for the fingers on a simplified MIDI keyboard. A draft is generated by
code, but a draft only lines notes up with onsets; what makes a chart feel *musical*
(a repeating rhythm shape, finger paths that follow the melody, rests where the music rests)
is judgement. So the MCP gives the model senses and checks, and the model chooses:

| Sense / hand | Tool | What it gives |
|---|---|---|
| Ears | `analyze_video_notes`, `music.json` | melody notes, kick/snare/hat hits, sections, loudness per measure |
| Eyes | `view_chart`, `look_at_video` | a picture of the chart beside the music; frames of the video |
| Reading | `inspect_chart` | measures next to the music they follow, which measures sound alike, stats |
| Hands | `edit_chart` | applies rewritten measures; refuses anything unplayable, warns about density, reach, notes with nothing to hear |
| Knowledge | `choreography_guide` | what a good chart feels like and the working method |

The same tools are available from a shell for agents without MCP: `video2sm-review inspect | view | frames | edit | merge`.
`make_song_from_video` writes the draft and `music.json`; the model then reworks it section by
section. `inspect_chart`'s stats include `rhythm_vocabulary`, the share of measures that use one of
the six most common rhythm patterns, a measure of how regular the chart is.

## How the draft is made

1. `ffmpeg` extracts the audio (Ogg Vorbis) and grabs banner/background frames.
2. Beat analysis finds BPM and the first beat (accurate to ~1 ms on clean tracks).
3. **With Demucs installed (the default when available):** the song is separated into
   vocals / drums / bass / other. The vocal melody is transcribed into notes (pYIN pitch
   tracking), and kick / snare / hi-hat hits are read from the drum stem.
4. Charts follow the music: each melody note becomes a chart note on its sung onset, in
   the lane its pitch maps to (higher pitch, further right); long sung notes become holds;
   drum hits fill in around the vocal line, more of them as difficulty rises.
5. **Without Demucs** (or `chart_source: "mix"`): onsets are found in the full mix instead,
   snapped to a 16th-note grid, and columns are assigned by hand alternation and band.
6. The `.ssc` is rendered, re-parsed, and validated before it is reported as done.

## Tools

| Tool | Purpose |
|---|---|
| `make_song_from_video` | Video in, song folder out (draft charts, `music.json`, banner, jacket, title cards). `difficulties`: `low` / `medium` / `high` (Easy / Medium / Hard) plus `beginner` (default: all four); `challenge`, `all` also accepted. `key_modes`: `kb7-single` (`7k`, default), `dance-single` (`4k`), `pnm-nine` (`9k`, `popn`), several allowed in one song. `holds`: hold notes on or off (default on). `chart_source`: `auto` (default), `stems` (requires Demucs), or `mix` |
| `download_video`, `make_song_from_url` | The same from a YouTube link. `rights_basis` is required (why you may use the material); it is recorded, not verified |
| `analyze_video_beats` | BPM / offset / confidence only, writes nothing |
| `analyze_video_notes` | What the music contains: BPM, the vocal melody as a list of notes (time, length, MIDI, name), pitch range, kick/snare/hat counts. Needs Demucs. Writes nothing |
| `choreography_guide` | What a good chart feels like and the working method (read before reworking a draft) |
| `inspect_chart` | Measures next to the music they follow, which measures sound alike, and stats (density, rhythm regularity, leaps) |
| `view_chart` | A picture of measures beside the melody and drums |
| `look_at_video` | A contact sheet of video frames, labelled with time |
| `edit_chart` | Rewrite / copy / repeat / clear measures; refuses unplayable edits, warns about density and reach; `dry_run` |
| `align_chart` | Snap notes onto the sung attack or drum hit they answer; run after choreographing |
| `validate_song` | Parse an `.ssc`, check timing, notes, and referenced files |
| `adjust_song_offset` | Fix sync: positive `delta_ms` = notes later |

## How it works

Code gives the model senses and checks; the model makes the choreography decisions. See the
[main README](../README.md#how-the-mcp-server-works) for the pipeline and the review loop. In short:
`ffmpeg` and beat tracking, optional Demucs stems, pYIN melody and drum onsets are written to `music.json`;
a draft is generated from them; the model reviews it with `inspect_chart` / `view_chart` / `look_at_video`,
rewrites it with `edit_chart`, and `align_chart` then snaps the notes to the exact attacks.

Songs go to `$VIDEO2SM_SONGS_DIR`, defaulting to the `Songs` folder next to the `video2sm` directory (the root of the
Etterna checkout). Restart Etterna (or reload songs) to see new ones.

## Key modes

| Mode | Steps type | Columns | Notes |
|---|---|---|---|
| `7k` (default) | `kb7-single` | 7 | Etterna's `kb7` game mode, played on S D F Space J K L |
| `4k` | `dance-single` | 4 | Etterna's main mode |
| `9k` | `pnm-nine` | 9 | Only listed in Etterna's popn game mode. Etterna ships no default keyboard binding for the four white and green buttons, so bind all nine in the key settings |

Holds appear on Medium, Hard and Challenge (about 4 / 6 / 8% of notes at most),
one at a time, with no other note in the held column and no jumps while it is held.

## Setup

```bash
uv sync
claude mcp add video2sm -- "$PWD/.venv/bin/video2sm-mcp"
```

Charts that follow the melody and drums need the optional stem separation:

```bash
uv sync --extra stems   # Demucs + PyTorch, a few hundred MB
```

The first separation of a song takes about a minute on an Apple M-series CPU (plus a
one-time model download of about 80 MB); results are cached under
`~/.cache/video2sm/stems` (`$VIDEO2SM_CACHE_DIR`), so rebuilding the same song is fast.
Set `$VIDEO2SM_DEMUCS_DEVICE` to use a GPU (`mps`, `cuda`).

Requires `ffmpeg` on `PATH`. `setuptools<81` is pinned because `simfile` still
imports `pkg_resources`.

## Tests

```bash
uv run pytest --cov=video2sm
```

## Limits

- Assumes a constant tempo; tempo changes and live recordings produce a warning.
- The melody is read from the vocal stem with a monophonic pitch tracker: instrumental
  tracks without a lead voice produce few melody notes (drums and bass still shape the
  chart), and fast runs or harmonies are simplified to one line.
- Sync is the one thing worth checking by ear. Use `adjust_song_offset` to fix it.
- Charts are algorithmic, not hand-made: playable and musical, not tournament-grade.
- Holds come from sustained energy in the mix, not from tracking individual instruments,
  so on staccato music there are few of them.
- Difficulty is tuned for casual play: about 0.9 / 1.4 / 2.3 / 3.3 / 4.5 notes per second
  (Beginner to Challenge). On 9 keys, consecutive notes stay within 4 columns (about 2 on
  average) so the hands don't leap across the keyboard.
